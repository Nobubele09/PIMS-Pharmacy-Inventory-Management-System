# Pharmacy Inventory Management System (PIMS)

## HealthFirst Pharmacy

The Pharmacy Inventory Management System (PIMS) is a Java desktop application developed for HealthFirst Pharmacy.

The system is designed to manage pharmacy inventory, process sales, manage users and suppliers, and generate business reports.

## Technologies

- Java
- Java Swing/AWT
- JDBC
- MySQL
- Git
- GitHub

## Main Modules

- User Authentication
- Role-Based Access Control
- Medicine Management
- Supplier Management
- User Management
- Cashier Point of Sale
- Sales and Billing
- Sales Reports
- Item-Wise Reports
- Low Stock Reports
- Expiry Reports

## User Roles

### Administrator
The administrator can:
- Manage medicines
- Manage suppliers
- Manage cashier accounts
- View reports

### Cashier
The cashier can:
- Process sales
- Generate bills
- Check medicine stock
